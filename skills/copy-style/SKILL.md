# Copy style

Two small, always-on rules for English copy shown to users (UI strings,
messages, metadata/`siteConfig` descriptions, marketing text). Both apply
only to user-facing strings — code, comments, and internal docs are
unconstrained.

## No Oxford comma

Don't use the serial comma before the final **and**/**or** in a list of
three or more.

```
Bad:  production, songwriting, recording, mixing, release, and publishing
Good: production, songwriting, recording, mixing, release and publishing
```

Keep a comma before **and** when it joins two independent clauses, not a
list item:

```
Good: Hire the room, and stay in the chair.
```

## No em dash

Don't use an em dash (`—`) or a double hyphen (`--`) as a clause break or
title separator. Prefer a colon, comma, period or parentheses.

```
Bad:  Open daily — weekdays until 6pm
Good: Open daily: weekdays until 6pm
```

```
Bad:  Free delivery on orders — mainland UK only.
Good: Free delivery on orders: mainland UK only.
```

An en dash in a numeric range (`150–160`) is fine — this targets the em
dash and double-hyphen used as punctuation, not ranges.
